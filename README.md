# AI Sana

MVP платформы практических задач: бизнес оформляет задачу, команды выбирают её и отправляют предложения, а представитель бизнеса вручную принимает решение.

## Стек

- React + TypeScript + Vite
- CSS
- localStorage для демо-данных; сервер и регистрация для хакатонного MVP не нужны

## Запуск

```sh
npm install
npm run dev
```

## Работа в двух ветках

- `feat/business-flow` — создание задачи, уточнения, карточка, оценка готовности и публикация.
- `feat/team-marketplace` — каталог, карточка задачи для команды, отклик и ручное решение бизнеса.

Общий контракт находится в `src/shared/types.ts`, чтение и запись демо-данных — в `src/shared/store.ts`. Компоненты живут в независимых каталогах `src/features/business` и `src/features/marketplace`, чтобы уменьшить конфликты при слиянии.
